# Phase 3 — LLM-assisted advisory diagnostics

This extension builds a read-only LangGraph workflow around a bounded Evidently
summary and fixed, allowlisted Prometheus queries. It is a **prototype**:
it does not grant model, cluster, cloud, GitHub, shell, or database write access.

Workflow: collect -> interpret -> propose -> gate. Recommendations are fixed
safe investigations, not executable remediation instructions. The LLM only
proposes a hypothesis and an investigation through a Pydantic-constrained
schema. The system falls back to deterministic diagnosis when the model fails.

## Tests

Install `langgraph`, `pydantic` and `pytest`, then run:

```bash
python -m pytest -q tests/test_llm_workflow.py tests/test_agent_diagnostics.py
```

No API keys are used in CI. `FakeLLM` exercises the real orchestration
and structured output contract; no external provider is called.

## Model usage (not enabled by default)

Instantiate a chat model that supports structured output and pass it into
`analyze`. For example, in your own trusted Python environment:

```python
from langchain_openai import ChatOpenAI
from agents.llm_workflow import LlmOpinion, analyze

llm = ChatOpenAI(model="gpt-4.1-mini").with_structured_output(LlmOpinion)
report = analyze("data/reports/iris_drift_summary.json", model=llm)
```

This optional example requires separately installing `langchain-openai` and
configuring credentials through the provider's supported secure mechanism.
Do not commit tokens or place credentials in the repository.

Evidence is read from a strict summary schema; the agent cannot choose
arbitrary queries or URLs. Prometheus is only reached at loopback, so with
the current Docker Compose layout a development operator should run the
agent on the same host, after a report exists. Failures in retrieving
infrastructure metrics are explicitly included in the result.

### Current limitations

- Human approval is represented by `pending_human_review`, not persisted
  or granted. There is no action executor or user approval UI yet.
- A hypothesis generated by an LLM is not proof of cause, nor proof that the
  model's accuracy changed.
- Prometheus read-only allowlists are hardcoded to the Iris demonstration.
- Only anonymized aggregated evidence reaches the LLM.
- Before supporting external clients, add tenant-aware authentication,
  explicit consent to telemetry processing, durable incident storage, and
  regression benchmarks for untrusted evidence/prompt injection.
